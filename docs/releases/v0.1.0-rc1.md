# GAPD-7500 OpenWrt v0.1.0-rc1

첫 공개 시험판입니다. 공식 OpenWrt 커밋
`9f62ca8ff14d701928b425b53d0093de80eb0df6`에 이 저장소의 GAPD-7500 패치를
적용해 빌드했습니다.

실제 Davolink GAPD-7500(순정 1.06.08)에서 initramfs RAM 부팅과 factory UBI의
비활성 슬롯 설치, NAND 자동 부팅, LAN1, LuCI, SSH, overlay, firewall4, 두 무선
PHY/AP 인터페이스 생성을 확인했습니다.

받을 파일:

- `openwrt-qualcommax-ipq60xx-lg_gapd-7500-initramfs-uImage.itb`
- `openwrt-qualcommax-ipq60xx-lg_gapd-7500-squashfs-factory.ubi`
- `SHA256SUMS`

반드시 initramfs로 먼저 RAM 부팅하세요. factory UBI는 순정 웹 업그레이드 파일이
아니며, 현재 사용 중인 rootfs에 쓰면 안 됩니다. sysupgrade는 아직 지원하지 않아
릴리스에서 제외했습니다.

아직 확인하지 못한 항목도 있습니다. Wi-Fi는 드라이버와 AP 인터페이스까지
올라오지만 외부 클라이언트에서 beacon/연결/전송을 확인하지 못했습니다. WAN,
LAN2, USB 장치, 물리 버튼, 전원 완전 차단 후 부팅, 순정 슬롯 복귀도 남아 있습니다.
일상용 공유기를 바로 교체하기보다는 UART와 원본 백업을 갖춘 시험 기기에서
사용하는 편이 좋습니다.
